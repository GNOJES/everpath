# 무료 에셋 전장 비교

미니 월드(`mini/`)는 기본 화면에 적용된다. 개발 서버에서는 `/?art=puny`, `/?art=ninja`, `/?art=mini`, `/?art=original`로 비교할 수 있다. 전장은 원본 타일·나무·소품을 세로로 반복할 수 있게 조합했다. 기본 자세, 초상화, 슬라임은 원본 스프라이트 시트에서 고른 한 프레임을 사용한다.

| 폴더 | 제작자와 원본 | 사용 파일 | 라이선스 |
| --- | --- | --- | --- |
| `puny/` | Shade의 [Puny World](https://merchant-shade.itch.io/16x16-puny-world)와 [Puny Characters](https://merchant-shade.itch.io/16x16-puny-characters) | `punyworld-overworld-tileset.png`, `Warrior-Red.png`, `Archer-Green.png`, `Mage-Cyan.png`, `Slime.png` | CC0 1.0 |
| `ninja/` | Pixel-Boy와 AAA의 [Ninja Adventure](https://pixel-boy.itch.io/ninja-adventure-asset-pack) | `TilesetFloor.png`, `TilesetVillageAbandoned.png`, Knight·Hunter·SorcererOrange 유휴 프레임, Sword·Bow·MagicWand 소품, `Slime.png` | CC0 1.0 |
| `mini/` | Kurt Gabriel Sotelo와 octoshrimpy의 [Mini World Sprites](https://merchant-shade.itch.io/16x16-mini-world-sprites) | `Grass.png`, `TexturedGrass.png`, `Trees.png`, `PineTrees.png`, `Rocks.png`, `SwordsmanRed.png`, `Slime.png` | CC0 1.0 |

`mini/`의 궁수는 Puny Characters의 `Archer-Green.png` 오른쪽 측면에 Ninja Adventure의 활을 조합했다. 시위가 궁수 쪽에 오도록 배치했다. 마법사는 Puny Characters의 `Mage-Cyan.png` 모자와 로브 네 가지 색을 보라색으로 치환하고 Ninja Adventure의 지팡이를 조합했다.

`mini/*-motion.png`는 위 영웅 원본 시트에서 이동 네 프레임과 기본공격 세 프레임을 뽑아 40×40 셀에 발을 기준으로 배치했다. 위에서부터 측면·정면·후면 순서이며 좌측 측면은 Phaser에서 반전한다. 궁수와 마법사의 이동 프레임에는 같은 활과 지팡이를 합성했다. 마법사의 공격 자세에도 보라색 복장과 푸른 지팡이 보석을 적용했다.
