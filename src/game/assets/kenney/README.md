# 동화풍 숲 CC0 비교 소재

아래 파일은 Kenney Vleugels의 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 소재다.

- [Tiny Town 1.1](https://kenney.nl/assets/tiny-town): `blossoms.png`는 `tile_0002.png`에서 바닥색을 투명 처리하고 꽃을 분홍색으로 바꿨다. `shrub.png`와 `sprout.png`는 각각 `tile_0005.png`와 `tile_0017.png`의 윤곽과 잎을 동화풍 숲의 청록 팔레트로 조정했다. [Kenney가 올린 공개 ZIP](https://opengameart.org/content/tiny-town)에서 추출했다.
- [Interface Sounds](https://kenney.nl/assets/interface-sounds): `click-001.mp3`는 `click_001.ogg`의 MP3 변환본이다. [변환본 출처와 크레딧](https://github.com/manuel-palacio/brickstorm/blob/main/CREDITS.md#sound-effects-all-cc0)을 참고한다.

개발 서버의 `/?art=storybook-cc0`에서 사용한다.
