# EVERPATH · The Verdant Wilds

Phaser 4 + TypeScript로 만든 세로형 판타지 로그라이트 서바이버 파일럿입니다. 이동에만 집중하면 영웅이 자동으로 공격합니다. 경험치로 능력을 선택하고, 원정에서 모은 골드로 다음 도전을 준비하세요.


## 모바일 웹 플레이테스트

**고정 테스트 주소** [everpath-roan.vercel.app](https://everpath-roan.vercel.app/)

[GitHub의 `main` 브랜치](https://github.com/GNOJES/everpath/tree/main)에 푸시하면 Vercel `everpath` 프로젝트가 빌드하고 성공한 버전을 고정 주소에 적용합니다. 모바일 테스트를 이어갈 때는 이 주소를 북마크해 사용하세요.

웹 저장은 브라우저 프로필과 사이트 주소의 조합에 묶입니다. 같은 브라우저의 같은 프로필에서 고정 주소를 사용하면 배포 후에도 `everpath.save.v1`에 저장된 골드·영구 강화·원정 기록을 이어서 읽습니다. 기기나 브라우저 프로필을 바꾸거나 사이트 데이터를 지울 때는 설정의 JSON 백업을 사용하세요.

세로 화면 전체에 전장과 상단 상태 표시줄을 배치했습니다. 첫 프레임에 슬라임 세 마리가 등장하고, 전사는 기본 검격으로 범위 안의 적 탄환 하나를 제거합니다. 전투 음악과 보스 처치 연출을 새로 적용했습니다.

v0.6.0에서 화면의 아트와 메뉴, 적 스폰 방향, 장판 예고, 세 캐릭터의 전투 스타일을 개편했습니다. [전장과 전투 개편 검증](docs/playtests/web-v0.6.0.md)

v0.6.1은 일반 적을 정면 상단과 좌우 상단에서만 등장시킵니다. [상단 대기 비교](docs/playtests/web-v0.6.1.md)

v0.6.3부터 측면 적은 예고 없이 진입합니다. 전사 기본 검격은 70°에서 시작해 진화 후 112°까지 넓어집니다. 전투에서 약 75초 길이의 [오케스트라풍 원곡](scripts/music/README.md)이 반복 재생됩니다.

v0.6.4에서는 원정 결과의 **숲 다시 도전**이 영웅 선택을 열고, 영구 강화의 **− / +**로 항목별 환불과 구매를 할 수 있습니다. 새 구매는 실제 결제한 골드를 돌려줍니다. 이전 저장은 레벨별 구매 이력이 없어 저장된 총 투자액을 레벨 비용 비중으로 나눠 환불합니다. [초반·보스 비교](docs/playtests/web-v0.6.4.md)

v0.6.5에서는 전사의 충돌 피해와 마법사의 해골 궁수 화살 피해를 낮췄습니다. 6분에 등장하는 두 그롬은 돌진 후 더 오래 멈추고, 장판 범위가 줄었습니다. [무강화 6분전 비교](docs/playtests/web-v0.6.5.md)

v0.6.6부터 모르바의 마법 저항은 마법사의 영구 공격력 강화가 10~13단계로 오를 때 점차 낮아집니다. 13단계부터는 v0.6.5와 같은 피해 배율이 적용됩니다.

v0.6.7에서는 적이 떨어뜨린 동전·회복 아이템과 그롬의 보물 상자를 가까이 가서 획득합니다. 회복 아이템은 원정당 최대 두 개입니다. 영구 강화에서 **시간의 회중시계**를 구매하면 원정당 최대 세 번, 전장 왼쪽 아래 버튼으로 적과 전장 시간을 2초간 멈출 수 있습니다.

### 앱 저장을 웹으로 옮기기

1. 기존 Android 앱의 **설정 → JSON 백업 내보내기**로 파일을 저장합니다.
2. 같은 휴대폰에서 웹 게임을 열고 **설정 → 백업 파일 선택 → 이 백업으로 복원**을 누릅니다.
3. 이후 진행 상황은 해당 브라우저와 웹 주소에 저장됩니다. 기기나 브라우저를 바꿀 때는 새 백업 파일을 내보내 옮길 수 있습니다.

### 같은 Wi-Fi에서 최신 빌드 테스트하기

```bash
npm ci
npm run build
npm run preview -- --port 4173 --strictPort
```

터미널이 표시하는 **Network** 주소를 같은 Wi-Fi에 연결된 휴대폰에서 엽니다. 외부 정적 호스팅에 올릴 때는 빌드 결과인 `dist/` 폴더를 배포 루트로 사용합니다.

## v0.4.3 · 저장 데이터 백업과 복원

1. 앱을 삭제하거나 기기를 바꾸기 전에 타이틀의 **설정 → JSON 백업 내보내기**를 누릅니다. Android 파일 선택기에서 다운로드 폴더 또는 연결된 클라우드 저장소를 선택합니다. 웹에서는 JSON 파일이 다운로드됩니다.
2. 새 기기로 이동할 때는 이 파일도 함께 옮깁니다. 새로 설치한 앱에서 **설정 → 백업 파일 선택**으로 JSON을 열고, 골드·강화 레벨 합계·원정 기록 수를 확인합니다.
3. **이 백업으로 복원**을 누르면 현재 데이터를 파일에 담긴 시점으로 교체합니다. 보유 골드, 영구 강화와 환불액, 최고 기록, 최근 원정 최대 20건, 도전 해금, 음량 설정이 포함됩니다. 플레이 중인 원정은 저장 대상에서 제외됩니다.

Android 16 에뮬레이터에서 다운로드 폴더에 내보낸 JSON이 앱 삭제 후에도 남는 것을 확인했습니다. 재설치한 앱에서 복원한 전체 저장 데이터가 재시작 후에도 원본과 일치했습니다. [검증 결과](artifacts/android/validation/backup-roundtrip-result.json)

## v0.4.2 · Android 저장 이전

같은 서명으로 만든 APK를 기존 앱 위에 설치한 뒤 한 번 실행하세요. Android 앱은 기존 WebView 저장에서 골드·영구 성장·원정 기록·설정을 자동으로 읽어 [Capacitor Preferences](https://capacitorjs.com/docs/apis/preferences)에 복사합니다. 다음 실행부터 Preferences의 최신 데이터로 이어집니다. 앱을 삭제하거나 앱 데이터를 지우면 내부 저장도 삭제됩니다. 일반 브라우저 저장은 기존 주소의 `localStorage`에 남습니다.

[업데이트 설치 검증](docs/preferences-upgrade-verification.md)에서 Android 16 에뮬레이터의 v0.4.1 → v0.4.2 덮어 설치 결과를 확인할 수 있습니다.

## v0.4.1 · 숲 원정 종료와 기록

10분에 나타나는 모르바를 처치하면 **결과 화면으로 종료**하며 전투가 계속되지 않습니다. 결과에는 전투 시간(일시정지 제외), 레벨, 처치 수·처치율, 놓친 수·비율, 전체 등장, 보스와 골드를 표시합니다. 놓친 수는 **등장−처치**, 비율은 **미처치÷전체 등장×100**이며 일반 적과 보스를 모두 포함합니다. 화면 밖 이탈·전환/상한 정리·종료 시 생존을 따로 보여줍니다. 등장0일 때 비율은0%입니다.

**설정 또는 결과 → 최근 원정 기록**에서 최근20회를 펼쳐 볼 수 있습니다. 기존 골드·영구 성장과 기록을 유지하고, 이전 버전에 없던 상세 집계를 소급 생성하지 않습니다. 다음 스테이지 자동 진행은 없으며, 숲 재도전은 사용자가 선택해 시작합니다. [종료·기록 검증 안내](docs/run-results-verification.md)를 참고하세요.

## v0.4.0 · 더 긴 재도전 성장과 사운드 보완

10:00 모르바 처치가 첫 목표이며 결계 붕괴 전100초 안에 처치해야 합니다. 보스HP를56,000으로 올리고 마법사의 광역·둔화 효율을 낮췄습니다. 영구 강화는 **각20단계**, 공격/HP6%·이동1%·골드2.5%씩 성장하고 비용은 `24 + 12L + 3L²`입니다. 기존 저장은 레벨을 두 배로 변환해 같은 보너스와 투자액·기록을 보존합니다. 성장의 제단의 전액 환불·재육성도 유지합니다.

정상HP1,038회 모의 원정에서 성장 비교와48개 연속 재도전 경로를 확인했습니다. 첫 클리어 중앙값은 전사18.5회·궁수14회·마법사12.5회이며, 최소는 각각12/8/5회입니다. 모든 경로가36회 한도 안에서 성공했습니다. 실제 사람의 기록을 보장하는 수치는 아닙니다. [최신 검증 보고서](docs/retune-audio-verification.md)에 전체 범위·실패 기록·조건을 남겼습니다. 이전10분 캠페인 설명은 [v0.3 기록](docs/campaign-verification.md)을 참고하세요.

사운드는 음악/효과음 실시간 음량·음소거, 음악 일시정지, 중단 시 예약음 정리와 재개를 보완했습니다. 무기·피격·보스·승리·패배 신호를 구분하고 출력 압축과 발성 상한을 적용했습니다. 실제 Web Audio 신호 검사와 브라우저 동작을 검증했으며 폰 스피커 청취는 별도 확인이 필요합니다.

무기5+해당 패시브2로 영웅별 무기를 진화합니다. 중간 보스는 2·4·6·8분에 등장하며, 클리어 후 도전1~3을 순차 해금합니다. 지역은 숲 1개, 일반 적 6종, 보스 3종, 무기 진화 3종입니다.

## 실행

Node.js **22.12 이상**과 npm이 필요합니다. Android CLI는 Capacitor 8의 Node 22 이상 요구사항을 따릅니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소를 여세요. 기본 포트는 5173이며, 포트를 직접 지정할 수도 있습니다.

```bash
npm run dev -- --port 5187 --strictPort
```

`localhost`가 다른 서비스로 연결되는 환경에서는 `http://127.0.0.1:5187/`을 사용하세요. 모바일 실기기에서는 같은 네트워크에서 터미널에 표시되는 Network 주소를 여세요. 로컬 방화벽 설정에 따라 접속 가능 여부는 달라집니다.

## Android 폰에서 테스트하기

APK 생성·서명과 Android16 에뮬레이터의 오프라인 실행/뒤로가기/홈 복귀/저장 검증을 완료했습니다. 상세 결과는 [Android APK 검증 기록](docs/android-apk-verification.md)에 있습니다.

테스트용 **debug APK**를 만들었습니다. 앱 이름은 **EVERPATH**, 패키지 ID는 `com.everpath.game`, 버전은 **`0.4.3` (versionCode 7)**입니다.

- APK: [artifacts/android/everpath-debug.apk](artifacts/android/everpath-debug.apk)
- SHA-256: [everpath-debug.apk.sha256](artifacts/android/everpath-debug.apk.sha256)
- 빌드 정보: [build-info.json](artifacts/android/build-info.json)

현재 APK는 약 **4.76 MB**입니다. 게임 이미지·소리·스크립트를 APK에 포함하므로 개발 서버, 같은 Wi-Fi, 로그인 없이 오프라인 실행할 수 있습니다. 첫 빌드에는 Gradle/Android 의존성 다운로드를 위한 인터넷이 필요합니다.

### 폰에서 진단 모드 사용

1. 타이틀 **설정 → 실기기 진단 · 로그 → 진단 켜기**를 누릅니다. 진단은 기본적으로 꺼져 있으며 켜기 설정만 다음 실행에 유지됩니다.
2. 이전 화면으로 돌아가 영웅을 선택하고 5~10분 플레이합니다. 전투 중 상단 진단 HUD에서 FPS, 프레임 p95/최대, 입력 대기 p95, DRAG/IDLE, 포인터 종류·ID, 터치 수와 이동 방향을 확인합니다. HUD 오른쪽 버튼 또는 **일시정지 → 실기기 진단 · 로그**로 진단 화면을 엽니다. 열면 전투가 일시정지됩니다.
3. 필요하면 영웅·화면 주사율·발열·문제 상황을 200자 메모에 남기고 **진단 로그 내보내기 (JSON)**를 누릅니다. Android 공유 화면에서 사용할 앱/저장 위치를 직접 선택하세요. 설치된 앱에 따라 저장 메뉴가 다르며, 공유 화면을 닫았다는 메시지가 저장 완료를 보장하지는 않습니다. 브라우저에서는 JSON 파일을 다운로드합니다.
4. 세 영웅을 같은 조건에서 비교하려면 영웅별 시작 전에 **새 기록 · 기존 기록 초기화**를 누르고 이전 로그는 먼저 내보내세요. 기록 초기화는 게임 저장 데이터에 영향을 주지 않습니다. **진단 끄기 · 기록 보관**은 수집을 멈추고 이번 실행의 로그를 남깁니다.

| 값 | 측정 기준 |
| --- | --- |
| FPS / 프레임 p95·최대 (ms) | 최근 약 1초의 원시 `requestAnimationFrame` 콜백 간격. Phaser 보정 FPS와 50ms 시뮬레이션 제한을 사용하지 않음 |
| p95 | 해당 구간 측정값 중 약 95%가 이 값 이하인 지점. 평균에 가려지는 느린 프레임/입력 확인용 |
| 50ms 초과 프레임 | 진단을 켠 동안 전체 화면에서 누적한 50ms 초과 간격 수. JSON에는 33.3/50/100ms 초과 수와 전투 진행 중 집계를 별도 저장 |
| 입력 → 게임 갱신 p95 (ms) | 수락한 이동 입력 이벤트의 타임스탬프부터 다음 전투 시뮬레이션 갱신까지의 소프트웨어 대기 시간. 일시정지/메뉴 입력과 무시된 보조 손가락은 제외. 구간 내 입력이 없으면 `—` |
| 터치/포인터 | 게임 캔버스가 관찰한 손가락 수, 주 포인터, 수락/무시/취소/캡처 해제/초기화 이벤트. 시스템 전체 터치 계측은 아님 |

프레임 콜백 간격과 입력 대기는 **GPU 표시 시간, 디스플레이 응답 시간, 실제 손가락 접촉부터 화면 변화까지의 지연을 측정하지 않습니다.** 홈/앱 전환·공유 화면·창 비활성화 대기는 FPS에서 제외하고 별도 시간으로 기록합니다. 복귀 후 전투는 직접 재개해야 합니다. 진단 표시와 수집 자체에도 작은 부하가 있으므로 성능 비교 시 모든 실행에서 같은 설정을 사용하세요.

JSON에는 세션/앱 버전, 기기 모델·제조사·Android/WebView 버전, 화면 크기/주사 간격, 영웅·체력·레벨·적/투사체/효과 수, 프레임/입력 요약, 수락·무시·리셋과 앱 상태/오류 이벤트, 메모가 포함됩니다. 기기 고유 ID, 전체 게임 저장, 임의의 키보드 입력 문자는 수집하지 않습니다. 자동 전송은 없습니다.

메모리에는 최대 **1,800개 구간 요약(약 30분, 화면 전환 시 짧은 요약이 추가될 수 있음)**과 **4,000개 이벤트**를 보관합니다. 이동 이벤트 로그는 최대 초당 5회로 묶고, 입력 대기 큐는 32개로 제한합니다. 한도 초과 시 가장 오래된 항목을 버리고 `retention.dropped*`에 개수를 남깁니다. 전체/전투 누적 통계는 남습니다. 앱 강제 종료·OS 메모리 회수·새로고침 시 메모리 로그와 메모가 사라지므로 **앱을 닫기 전에 내보내세요.** Android 임시 공유 파일은 앱 캐시에 최근 5개만 유지하고 별도 저장소 권한을 요구하지 않습니다. 공유한 사본의 보관은 선택한 앱에서 관리합니다.

v0.1.0과 패키지 ID/디버그 서명이 같으므로 새 APK를 기존 앱 위에 설치하거나 `adb install -r`로 업데이트할 수 있습니다. 삭제 후 재설치하면 저장 데이터가 지워지므로 업데이트 설치를 사용하세요. [진단 모드 검증 기록](docs/device-diagnostics-verification.md)에 자동 검사와 에뮬레이터 결과를 구분해 정리했습니다.

### APK 파일로 설치

1. 위 APK를 USB 파일 전송 등으로 안드로이드 폰에 복사합니다.
2. 폰의 파일 앱에서 `everpath-debug.apk`를 열고 설치합니다. 파일 앱의 **알 수 없는 앱 설치** 권한 요청이 나오면 설치에 사용할 앱에 대해 허용합니다. 메뉴 이름은 제조사/OS마다 다릅니다.
3. 앱 목록에서 **EVERPATH**를 실행합니다.

파일로 설치할 때는 개발자 옵션이나 USB 디버깅이 필요하지 않습니다. 이 파일은 실기기 테스트용 디버그 서명 APK이며 스토어 출시용 서명은 포함하지 않습니다.

### USB / ADB로 설치

1. 폰의 개발자 옵션에서 **USB 디버깅**을 켭니다.
2. 데이터 전송이 가능한 USB 케이블로 연결하고 폰에 표시되는 디버깅 허용 요청을 확인합니다.
3. Android SDK의 `platform-tools`를 PATH에 추가하거나 `adb`의 전체 경로를 사용합니다.

```bash
adb devices -l
npm run android:install
```

`device` 상태의 기기가 정확히 하나면 그 기기에 설치합니다. 여러 폰이나 에뮬레이터가 있으면 자동 선택하지 않으며, 표시된 serial을 지정해야 합니다.

```bash
npm run android:install -- SERIAL
```

Node 없이 ADB만 사용할 경우:

```bash
adb -s SERIAL install -r artifacts/android/everpath-debug.apk
adb -s SERIAL shell am start -n com.everpath.game/.MainActivity
```

`SERIAL`은 `adb devices -l`에 표시된 실제 값으로 바꾸세요. `android:install`은 설치만 수행하므로 완료 후 앱 아이콘으로 실행할 수 있습니다. `-r` 업데이트는 같은 앱 ID와 같은 디버그 서명일 때 저장 데이터를 유지합니다. 웹 브라우저와 APK의 저장 공간은 별개입니다.

다른 컴퓨터의 디버그 키로 다시 빌드한 APK는 기존 앱에 업데이트할 수 없는 경우가 있습니다. `INSTALL_FAILED_UPDATE_INCOMPATIBLE`이면 원래 서명 키로 빌드해야 저장을 유지할 수 있습니다. 앱 삭제/앱 데이터 지우기는 게임의 로컬 저장을 지우므로 업데이트 문제를 해결하려고 먼저 삭제하지 마세요.

### 앱 조작과 저장

- 폰은 세로 방향으로 실행되며 시스템 바/노치 영역을 제외한 공간에 게임을 배치합니다. API36에서 큰 화면 기기는 OS 정책에 따라 방향 잠금을 다르게 처리할 수 있습니다.
- 화면 잠금·홈 이동·앱 전환 시 입력/전투를 멈추고 진행 기록을 저장하며 소리를 중단합니다. 복귀 후에는 **모험 계속하기**를 눌러 재개합니다.
- 뒤로가기: 전투 중에는 일시정지, 정지 상태에서는 재개, 선택/설정/상점에서는 이전 화면으로 이동합니다. 필수 레벨업 선택은 뒤로가기로 건너뛰지 않습니다. 타이틀에서는 앱을 최소화합니다.
- 브라우저와 마찬가지로 진행 중인 전투 이어하기는 없습니다. OS가 프로세스를 종료하면 원정은 끝나고, 이미 저장한 골드·영구 강화·설정은 앱 데이터에 남습니다.

실기기에서는 이동/손 떼기, 멀티터치, 뒤로가기, 홈/잠금 복귀, 게임오버 후 구매와 재실행 저장 유지를 먼저 확인하세요. manifest 최소 버전은 **Android7(API24)**이며, 최신 Android System WebView/Chrome과 WebGL을 지원하는 기기가 필요합니다. 낮은 사양의 실기기 FPS·발열은 별도 측정 대상입니다.

## 플레이

- **PC:** WASD / 방향키, 또는 마우스 클릭 후 드래그.
- **모바일:** 플레이 영역 아무 곳이나 터치한 뒤 드래그. 그 위치가 이번 조이스틱의 중심이 됩니다.
- 손을 떼거나 터치를 취소하면 즉시 정지합니다. UI 버튼은 이동을 발생시키지 않습니다.
- **ESC / 상단 일시정지:** 전투 중단 / 재개.
- 창이 비활성화되거나 다른 앱으로 전환하고 화면 크기·방향이 바뀌면 자동 일시정지합니다.
- 공격·스킬·경험치·골드는 자동 처리됩니다.
- 강화 선택 중에는 전투와 스크롤이 정지합니다.
- 일시정지에서 **원정 마치고 타이틀로**를 선택해도 해당 원정에서 획득한 골드를 정산합니다.
- 전투 도중 새로고침하거나 브라우저를 강제로 종료한 경우에는 진행 중인 전투/미정산 골드를 복구하지 않습니다.

화면은 논리 해상도 **432×768**로 동작하며 화면 비율에 맞춰 확대/축소합니다. PC에는 기록과 도감이 추가되고, 모바일에는 세로 게임 영역이 표시됩니다. 가로 화면도 세로 플레이 영역을 유지하며, 짧은 화면의 메뉴는 내부 스크롤로 조작할 수 있습니다.

## 영웅과 능력

모든 영웅은 처음부터 선택할 수 있습니다. 기본 무기는 최대 **5레벨**, 각 영웅의 고유 보조스킬은 최대 **3레벨**입니다.

| 영웅 | 기본 HP / 이동속도 | 기본 무기 | 고유 보조스킬 |
| --- | --- | --- | --- |
| 로완 · 전사 | 160 / 133 | 새벽의 검 — 근접 부채꼴 베기, 5레벨에 전 방향 검격 | 회전베기: 광역 피해 / 검기 발사: 관통 투사체 / 수호의 방패: 피해 방어 |
| 린 · 궁수 | 105 / 168 | 바람의 활 — 빠른 화살, 3·5레벨에 발사 수 증가, 4레벨에 관통 | 다중 화살: 부채꼴 일제사격 / 관통 화살: 강력한 관통 공격 / 화살비: 밀집 지역 지연 공격 |
| 엘라 · 마법사 | 85 / 139 | 별빛 지팡이 — 추적 마법탄, 3·5레벨에 발사 수 증가, 5레벨에 범위 폭발 | 연쇄 번개: 연속 전이 / 화염 폭발: 밀집 지역 범위 공격 / 냉기 오라: 주기 피해와 둔화 |

공통 패시브는 공격력 +15%, 공격 주기 단축 +10%, 기본 최대 체력 +18%와 회복, 기본 이동속도 +8%입니다. 각각 최대 5회 강화할 수 있습니다. 최대 체력 증가 수치는 기본 체력을 기준으로 더해지며, 공격 주기 보너스는 `기본 주기 / (1 + 보너스 합계)`로 계산합니다.

보조스킬은 강화 선택에서 처음 습득해야 발동합니다. 기본무기의 피해·가속 강화는 해당 무기에 적용되고, 공통 공격력·가속 패시브는 무기와 보조스킬에 모두 적용됩니다. 수호의 방패는 항상 한 번만 방어하며 2·3레벨에 재충전이 빨라집니다. 선택지는 해당 영웅에게 유효한 능력으로 구성하고, 중복·최대 레벨 능력을 제외합니다. 3개 미만이면 남은 선택지만 표시하며, 선택지가 소진되면 자동으로 진행합니다. HP가 45% 미만이면 아직 최대가 아닌 생명의 뿌리 선택지 하나를 보장해 회복 여부를 직접 선택할 수 있게 합니다. 한 번에 여러 레벨을 올렸다면 필요한 선택을 차례로 처리합니다.

## 원정과 영구 성장

일반 적은 슬라임, 고블린, 박쥐, 해골 궁수, 가시 갑주병, 독안개 주술사로 구성됩니다. 체력과 정예 비중은 시간이 지나면서 커집니다. 마법사의 기본 유도탄과 집중 낙뢰·화염 낙인·별똥별, 전사의 갑주 가르기, 궁수의 매의 눈과 기본 화살의 첫 명중은 갑주병·정예·보스에게 30% 추가 피해를 줍니다.

첫 2분에는 느린 적 위주로 한 마리씩 등장하고, 처치당 경험치에 초반 보너스가 붙습니다. 적이 나오는 속도와 체력은 2분에 일반 수치에 도달합니다.

| 시간 | 편성 |
| --- | --- |
| 2:00 | 그롬 1마리 |
| 4:00 | 그롬 2마리 |
| 6:00 | 그롬 1마리, 가시 포격수 바르크 1마리 |
| 8:00 | 그롬 2마리, 바르크 2마리 |
| 10:00 | 모르바, 7.5초 간격 일반 적 증원 |

보스는 화면 상단에서 내려오며, 그롬은 주황색, 바르크는 민트색, 모르바는 보라색 체력바를 사용합니다. 바르크는 예고한 두 지점에 순차 포격합니다. 9:15부터 일반 적 출현이 서서히 줄고, 모르바전에서는 새로 들어온 증원이 동시에 최대 3마리까지 존재합니다. 모르바를 처치하면 클리어·정산하며, 최종 결계는 100초 뒤 붕괴합니다.

배경 이동 속도는 초당 22 논리 픽셀로 플레이어의 이동과 독립적입니다. 화면 밖으로 지나간 적은 정리하며, 놓친 적 때문에 피해가 발생하지 않습니다.

게임오버 또는 클리어 시 영웅·생존 시간·레벨·처치 수·보스 처치·골드를 기록합니다. 골드 보상은 원정 ID로 중복 지급을 막고, 종료한 최근 128개의 ID를 저장합니다.

| 영구 강화 | 레벨당 효과 | 최대 레벨 |
| --- | --- | --- |
| 힘의 맹세 | 공격력 +6% | 20 |
| 참나무 심장 | 최대 HP +6% | 20 |
| 바람의 걸음 | 이동속도 +1% | 20 |
| 황금의 축복 | 골드 획득량 +2.5% | 20 |

구매 비용은 `24 + 12L + 3L²` (L=현재 레벨)입니다. 세 영웅이 효과를 공유하며 다음 원정부터 적용됩니다. 정상적인 첫 플레이에서 기본 구매가 가능하도록 일반 적도 골드를 지급합니다. 의도적으로 전투를 하지 않고 종료하면 보상이 없을 수 있습니다.

## 저장

키는 `everpath.save.v1`, 스키마 버전은 1입니다. 보유 골드, 영구 강화, 최고 기록, 완료한 원정 수, 마지막 영웅, 최근 20회 원정, 음악/효과음 설정과 정산 ID를 저장합니다. 손상된 JSON·미지원 버전은 기본값으로 복구하고 비정상 수치/영웅 ID는 검증합니다.

Android 앱은 Preferences에 기록하고, 웹은 브라우저 주소별 `localStorage`에 기록합니다. Android 시작 시 읽기나 이전에 실패하면 다시 시도할 수 있습니다. 플레이 중 쓰기가 실패하면 화면의 **다시 저장** 버튼으로 현재 데이터를 저장할 수 있습니다.

## 밸런스 조정 위치

주요 수치는 **`src/game/config.ts`** 한 곳에서 조절합니다.

- `HEROES`: 기본 HP·이동·피해·공격 주기·사거리·투사체 속도·고유 스킬.
- `SKILLS`: 발동 주기·피해 배율·범위·기본 발사/전이 수.
- `ENEMIES`: 기본 HP·속도·피해·충돌 반경·경험치.
- `BALANCE`: XP 증가 곡선, 스폰 주기, 보스 시간, 성장 상한, 스킬 배율, 영구 비용.
- `WORLD`: 논리 해상도, 스크롤, 조이스틱 반경/데드존, 무적 시간, 엔티티 상한.
- `PERMANENT`, `PASSIVES`: 영구 성장/원정 패시브 정의.

적 등장 조합과 생성 곡선은 `encounters.ts`, 개별 AI 패턴은 `simulation.ts`의 `moveEnemies()`, 새 공격 동작은 `basicAttack()` / `castSkill()`에서 관리합니다. 새로운 캐릭터가 기존 무기/스킬 동작을 공유하면 데이터 추가 중심으로 확장할 수 있고, 완전히 새로운 공격 동작은 공통 전투 경로에 동작을 추가해야 합니다.

## 성능과 디버그

`/?debug`로 열면 FPS·적 수·투사체 수·플레이어 좌표·드래그 상태를 표시합니다. 일시정지 시 게임 로직과 배경/전투 애니메이션을 멈춥니다. 조이스틱 반경을 넘는 긴 드래그에서는 기준점이 손가락을 따라 움직여 반전 조작을 쉽게 합니다. 입력은 터치 취소, 포인터 캡처 해제, blur, resize에서 초기화됩니다.

최대 적 100, 투사체 180, 이펙트 60, 지연 범위 공격 12개를 유지합니다. 이미지·피해 숫자는 재사용하는 렌더링 풀로 관리합니다. 사라진 시뮬레이션 엔티티는 배열에서 정리하고 이동 프레임은 최대 50ms로 제한해 비활성화 후 순간이동을 방지합니다. 일반 적 상한에 도달해도 보스가 등장할 공간을 확보합니다.

실제 중저가 안드로이드 기기의 FPS·배터리·발열은 측정하지 않았습니다. Phaser 4와 그래픽 드라이버 호환성을 실기기에서 확인해야 합니다. Phaser 엔진이 포함된 JS는 gzip 약 406KB이며 Vite가 500KB 청크 경고를 표시합니다. 빌드는 성공하며, 다음 최적화 단계에서는 장치 프로파일링 결과를 바탕으로 엔진 번들 구성과 이펙트 상한을 조절하는 것이 좋습니다.

## 구현 상태와 후속 작업

요청한 파일럿의 타이틀 → 영웅 선택 → 자동 전투 → 레벨업 → 게임오버 → 영구 강화 → 재도전을 구현했습니다. 세 영웅, 고유 스킬 9종, 일반 적 4종, 돌진/범위 보스, 독립 스크롤, 조이스틱/키보드, 음량 설정, 저장 복구와 구매·정산을 포함합니다.

이번 범위에서 제외한 기능은 갈림길, 다른 지역, 전투 이어하기, PWA 오프라인 설치, 광고·결제·계정·온라인 랭킹입니다. 파일럿 그래픽은 원본 코드로 생성하고, 외부 게임 이미지·음악은 사용하지 않습니다.

후속 확장은 (1) 실기기 성능 및 5~10분 회피 플레이 밸런스 조정, (2) 분리한 스폰 데이터를 갈림길·지역 구간을 관리하는 EncounterDirector로 확장, (3) 캐릭터 방향별/걷기 스프라이트 추가, (4) 서비스 워커와 웹 앱 매니페스트, (5) Android 실기기 프로파일링 및 배포 서명 구성 순서가 적절합니다. 현재 걷기 표현은 픽셀 스프라이트의 작은 위치 변화로 구현되어 있고 방향별 다중 프레임 애니메이션은 추가 개선 항목입니다.

검증 기록은 `docs/verification.md`를 참고하세요. 개발 중 기록한 스크린샷은 `test-results/`에 생성되며 소스 배포에는 필요하지 않습니다.
