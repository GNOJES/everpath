# 검증 기록

검증일: 2026-11-17 (Asia/Seoul). 환경: macOS, Node 26.0.0, npm 11.12.1, Phaser 4.2.1. 실제 브라우저 검증은 이 컴퓨터에 설치된 Google Chrome을 사용했습니다.

## 최종 결과

| 명령 / 방식 | 결과 |
| --- | --- |
| `npm install --no-audit --no-fund` | 성공, package-lock.json 생성 |
| `npm test` | 4개 파일, 37개 테스트 통과 |
| `npm run build` | TypeScript 검사 및 Vite 프로덕션 빌드 성공 |
| `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e` | 브라우저 시나리오 4개 통과 |
| 인앱 브라우저 수동 확인 | 타이틀, 캐릭터 선택, 전사 전투와 27초 첫 레벨업, 강화 화면 확인 |

Vite는 Phaser 엔진을 포함한 500KB 초과 청크 경고를 표시합니다. JS는 약 1.45MB, gzip 약 392KB입니다. 오류가 아닌 크기 경고이며 빌드 산출물은 `dist/`에 생성됩니다.

## 순수 로직 / 입력

- 손상·미지원 버전·비정상 저장값을 기본값 또는 허용 범위로 복구.
- 동일 원정 중복 정산 방지 및 새 SaveStore로 불러온 후에도 중복 방지.
- 영구 강화 비용 차감·레벨 적용, 골드 부족/최대 레벨에서 구매 차단.
- localStorage 읽기/쓰기 실패 시 메모리 플레이 유지.
- 영웅별 유효 스킬, 중복 없는 강화 선택, 최대 레벨 제외, 3개 미만/0개 후보.
- 조이스틱 데드존·아날로그 이동량·대각선 정규화.
- 터치 위치 기준점, 화면 배율 변환, 릴리스·취소·두 번째 손가락·새 터치 위치.
- blur/resize 입력 초기화, 키보드/오른쪽 클릭/UI 영역 분리, 리스너 해제.
- 위/아래/정지 상태에서 동일한 배경 스크롤.
- 화면 경계, 일시정지 시 순수 상태 불변.
- 3개 캐릭터의 자동 공격과 XP/골드 보상.
- 고유 스킬 9종의 실제 발동 (기본 무기 초기 대기 중 확인).
- 여러 레벨 동시 획득, 잘못된 선택 차단, 모든 강화 소진 후 진행.
- 영구 HP 적용, 피격 무적, HP 0 게임오버, 새 원정 초기화.
- 180초 보스 등장, 스크롤 지속, 예고/돌진, 보스 처치 후 계속 진행.
- 일반 적 상한에서도 보스 자리 확보.
- 화면 아래로 지나간 적 제거 시 피해 없음.
- 사망 직후 같은 프레임의 처치/레벨업 회복 차단.
- 600초/12,000스텝 순수 시뮬레이션에서 적·투사체·이펙트·지연 공격 상한 유지. 이 테스트는 높은 HP와 최대 강화 마법사로 엔진 외부 로직의 누적 안정성을 검사하며, 일반 플레이 난이도나 실기기 10분 성능 측정은 아닙니다.

## 실제 브라우저 시나리오

1. **세 영웅과 화면 생명주기:** 타이틀, 각 영웅 선택/시작, ESC 정지, 시간 불변, 소리 설정, 재개, 원정 종료, 다음 영웅 시작. 페이지 런타임 오류 없음.
2. **실제 전투와 영구 성장:** 테스트에서 난수와 브라우저 시계를 제어하여 정상 전투 로직을 진행. 경험치 → 강화 선택 → 재개 → 자연 사망 → 결과 → 골드 보상 → 공격력 구매 → 새로고침 후 구매/잔액 복구. 전투 상태 강제 변경이나 생산 코드의 테스트 전용 조작 함수를 사용하지 않습니다. 페이지 런타임 오류 없음.
3. **360×640 터치:** Chrome의 실제 CDP 터치 시작/이동/취소/종료로 포인터 캡처를 사용. 디버그 좌표로 실제 2축 이동과 릴리스 후 정지 확인. 새 터치, 일시정지 UI와 이동 분리, 가로 넘침 없음. 페이지 런타임 오류 없음.
4. **320×568 작은 화면:** 영웅 선택 시작 버튼이 플레이 영역 안에 온전히 위치함을 좌표로 검사. 배경음/효과음 변경 후 새로고침 복구.

브라우저 스크린샷: `test-results/title-desktop.png`, `title-mobile.png`, `select-small-mobile.png`, `results-desktop.png`, `shop-desktop.png`, `pause-mobile.png`.

## 검토와 수정

별도 읽기 전용 코드 검토를 수행했습니다. 치명적/중요 수준의 추가 문제는 보고되지 않았습니다. 보조 검토와 추가 테스트로 확인한 아래 사항은 수정했습니다.

- 320×568 영웅 선택에서 하단 버튼 일부가 잘리던 현상: 작은 화면 간격 조정, 짧은 화면 메뉴 내부 스크롤 추가.
- 사망 프레임 후 자동 공격으로 경험치와 HP 회복이 발생하던 순서 문제: 사망 후 후속 전투 처리 중단. 실패 테스트에서 HP가 12.8로 복구되는 것을 재현한 후 수정·통과 확인.
- 영웅별 차이와 맞지 않던 공통 무기 설명: 데이터의 영웅별 설명으로 변경. 전사 5레벨은 전 방향 공격과 고리 이펙트.
- 게임은 정지했지만 일부 장면 애니메이션 시간이 흐르던 문제: 정지 중 장면 애니메이션 시계도 동결.

## 수행하지 않은 검증 / 남은 개선

- 중저가 Android 실기기, Android WebView/Capacitor, iOS Safari 실기기 성능·배터리·열 측정.
- 실사용자 회피 플레이를 통한 5~10분 난이도/세 캐릭터 간 정밀 밸런스 검증. 자동 테스트는 정상 흐름과 로직을 증명하며 재미를 증명하지 않습니다.
- 다수 브라우저 간 동시 탭 저장 충돌 방지. 현재 저장 모델은 브라우저 내 단일 플레이를 기준으로 합니다.
- 오프라인 PWA 설치, 다양한 기기별 GPU/오디오 정책 검증.
- 보스 렌더링의 실기기 직접 플레이 검증. 보스 등장/패턴/처치는 순수 시뮬레이션 테스트로 확인했습니다.

브라우저 자동화 실행 중에는 소스/의존성을 변경하지 마세요. Vite 전체 새로고침이 진행 중 원정을 초기화할 수 있습니다.

- `npm test`: 8개 파일, 50개 테스트 통과. 기존 검증에 실제 명중·추적·스킬 계수 분리·방패 충전·검 사거리·냉기 범위·저체력 선택지·연속 스폰·치명적인 지연 공격·반전 조작 회귀 검사를 추가했습니다.
- `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`: 5개 시나리오 통과. 실제 터치 반전, 두 번째 손가락 무시와 주 터치 해제, 리사이즈 자동 정지, 작은 화면, 전체 메뉴·저장 흐름을 확인했습니다.
- `npm run build`: 타입 검사와 Vite 빌드 성공. Phaser 포함 청크 크기 경고는 남아 있습니다.
- 정상 체력·영구 강화 없는 81회 비교 행렬의 수정 전/후 원본과 실패 기록을 보존했습니다.

- 전사는 마지막 근접 타격 수정 후 재실행했고, 궁수·마법사는 변경 영향이 없는 직전 완료 기록입니다. 최초 실패를 최종 통과로 바꿔 기록하지 않았습니다.
- 별도 읽기 전용 검토에서 집계 파일 덮어쓰기와 사망 후 지연 공격 처리를 찾아 수정했습니다. 최종 집계는 캐릭터별 원본과 일치함을 확인했습니다.

실기기 Android 성능 및 사람의 손맛은 이번 자동화에서 검증하지 않았습니다. [상세 보고서](playtest-2026-11-18.md)를 참고하세요.
