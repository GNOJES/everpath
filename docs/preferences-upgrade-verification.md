# Android 저장 이전 검증 · v0.4.2

Android 앱은 `everpath.save.v1` 게임 저장을 Capacitor Preferences 8.0.1로 관리합니다. 첫 실행에서 Preferences에 값이 없으면 기존 WebView `localStorage`의 JSON을 복사하고, 저장을 읽은 뒤 게임을 시작합니다. 기존 사본은 보관합니다. 이후에는 Preferences가 최신 데이터의 기준입니다. 읽거나 복사하지 못하면 시작 화면에서 다시 시도할 수 있고, 게임 중 저장이 실패하면 현재 데이터를 다시 저장할 수 있습니다. 웹 브라우저는 주소별 `localStorage`를 사용합니다.

2026-11-18, Android 16(API 36) 에뮬레이터에 기존 서명 APK v0.4.1을 설치했습니다. 검증용 클리어 기록과 성장 데이터를 넣고 기존 앱의 상점에서 실제로 구매해 골드 286, 공격 2단계, 이동 1단계, 정산된 원정 기록 1회가 저장된 상태를 만들었습니다.

같은 에뮬레이터에서 앱을 삭제하지 않고 `adb install -r`로 v0.4.2를 설치했습니다. 업데이트 첫 실행 후 Android `SharedPreferences` 파일과 기존 JSON의 모든 필드가 일치했습니다. 게임 화면에서도 골드, 영구 강화, 1,312마리 처치와 5마리 미처치 기록이 표시됐습니다. 이어서 체력 강화를 구매하고 앱을 강제 종료한 뒤 다시 실행했습니다. 골드 262, 체력 1단계와 기존 원정 기록이 그대로 유지됐습니다. WebView에 남은 이전 값은 새 구매를 되돌리지 않았습니다.

단위 검사 95개와 브라우저 시나리오 13개를 통과했습니다. 자동화에는 테스트용 저장과 에뮬레이터를 사용했습니다. 검증 스크립트와 JSON 비교 결과는 `artifacts/android/validation/preferences-upgrade.mjs` 및 `preferences-upgrade-result.json`에 있습니다.

v0.4.2의 버전 코드는 6이며 패키지 ID는 `com.everpath.game`입니다. 기존 앱 위에 설치한 뒤 첫 실행하면 이전됩니다. 앱 삭제나 앱 데이터 삭제는 내부 저장도 지웁니다.

APK 서명과 패키지 내 웹 파일을 검증했습니다. 파일 크기는 4,763,977바이트이며 SHA-256은 `5cb7e204be08b14a73eca86dc4911e38183a8106b691b17a6771f5819005ba12`입니다.
