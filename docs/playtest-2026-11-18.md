# 세 캐릭터 플레이 검증 · 2026-11-18

## 검증 조건

- 기본 체력, 영구 강화 0, 레벨 1에서 시작했습니다. 정상 처치 경험치와 제시된 강화만 사용하며 HP·경험치·스킬·적 상태를 강제로 수정하지 않습니다.
- 수정 전후 각각 81회: 캐릭터 3 × 시드 3(42·271·2026) × 이동 3(정지·순환·위험 회피) × 빌드 3(균형·무기·스킬 우선). 한 회 최대 600초 게임 시간, 30Hz 시뮬레이션과 10Hz 입력 판단입니다.
- 실제 브라우저는 Chrome의 390×844 모바일 터치 에뮬레이션입니다. 생산 App/Phaser를 실행하고 CDP 실제 터치 이벤트를 보냅니다. 가속한 브라우저 시계 기준의 게임 시간으로 측정했습니다.
- 시험용 HTML은 상태를 조회하고 입력 방향을 추천합니다. 전투 상태를 변경하는 기능은 없으며 생산 빌드에 포함되지 않습니다.
- 자동 조작은 재현 가능한 시험 조건입니다. 인간의 숙련도, 재미, 실기기 손맛을 대체하는 지표는 아닙니다.

## 자료와 해석

원본 시뮬레이션은 [수정 전](playtests/before.json), [수정 후](playtests/after.json)에 저장했습니다. `hpLost`/`hits`는 프레임의 순 HP 하락 관찰값으로, 같은 프레임의 회복과 보호막으로 막은 공격을 포함하는 총 피격량은 아닙니다.

균형 빌드의 초기 브라우저 반복에서는 5분 전에 종료되는 경우도 있었습니다. 실패도 `browser-round-1-summary.json`, `browser-round-2-summary.json`, `browser-round-3-*.json`, `browser-weapon-round-4.json`에 남겼습니다. 첫 두 회는 테스트 워커 교체 시 집계 파일을 덮어쓰는 결함이 있어, 요약에서 stdout으로 복구한 항목과 누락된 원본을 명시했습니다. 이후에는 캐릭터별 파일을 먼저 저장하고 집계합니다.

브라우저의 전역 난수 시드에는 렌더링·오디오 소비도 포함되어 순수 시뮬레이션의 같은 번호 시드와 동일한 적 배치를 의미하지 않습니다. 균형 빌드와 기본무기 우선 빌드를 바꿔 측정한 브라우저 기록도 통제된 수정 전후 비교로 해석하지 않습니다. 통제 비교는 같은 시험 정책을 적용한 81회 행렬입니다.

## 남은 검증

실제 Android 하드웨어에서 FPS·배터리·발열·터치 지연과 사람이 느끼는 조작감은 별도 확인이 필요합니다. 시계 가속 테스트의 화면 FPS를 실기기 성능 측정치로 사용하지 않았습니다. 난수 세 시드와 자동 조작 표본을 넘어서는 플레이 밸런스 확인도 이어갈 수 있습니다.
