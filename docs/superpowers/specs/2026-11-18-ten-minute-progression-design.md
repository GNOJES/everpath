# Ten-minute progression design
User authorizes implementation and delegates unspecified design defaults in the original brief. Latest request replaces endless-first pilot with a ten-minute boss objective and meaningful repeat-run permanent growth/reset.

Approaches: (1) only scale old endless stats: cheap, insufficient content/goal; (2) complete ten-minute forest with staged encounters, distinct final boss, evolutions and repeat goals: chosen implementation default; (3) multiple full regions now: delays validating the core loop. Keep three heroes and shared power-ups, like existing save and reference's refunded power-ups. Free full investment refund enables rebuilding without erasing records/settings. No paid or hardcoded purchase gate to boss damage; base-stat trials must fail while grown trials improve.

Deliverables: forest phases through minute10, normal enemies4→6, bosses1→2, scheduled middle bosses at3/6minutes and final boss at10, telegraphed final attacks and victory settlement. Boss fights stop normal arrivals at final arena; final has an escalating arena timer so indefinite kiting cannot trivialize it. Three hero-specific weapon evolutions with weapon/passive prerequisites. Stage objective/progress, milestone supply rewards, per-hero clear record, post-clear escalating challenge rank selected before run; first clear remains rank0 objective. Economic progression: shared4 stats, stronger growth, affordable early ranks, exact investment accounting/refund including old save migration. Existing save key retained, additive schema data, no loss of balances/settings. Full reset requires explicit in-game confirmation; this is a power-up refund only.

Verification: deterministic normal-HP play matrix at meta0/5/10 across heroes/seeds/builds, full retry-economy sequence, gate no zero-meta sample clear and max-meta clear exists for each hero; no simulated guarantee about every possible human play. Unit tests for final boss/victory ordering, phases, evolution legality, exact refund/migration/duplicate rewards; browser touch/economy/victory UI, existing diagnostics/native regression. Rebuild Android0.3.0/code3 and verify packaged assets/signature. Original art only; no copied reference assets.

Reference: Poncle's Google Play description https://play.google.com/store/apps/details?id=com.poncle.vampiresurvivors explicitly describes run gold/upgrades and free power-up refunds. Our10minute goal/curve are custom, not claimed to be Vampire Survivors' exact numbers.
