# v0.4.1 · 원정 종료와 몬스터 기록

10분에 등장하는 모르바를 처치하면 즉시 victory 상태로 종료하고 결과 화면을 표시한다. 전투 시간/스폰/공격/보상은 이후 증가하지 않는다. 100초 안에 처치하지 못하면 패배로 끝난다. 자동 다음 스테이지와 무한 연장은 없다. 기존 도전 단계는 사용자가 다시 시작하는 같은 숲의 난이도 선택이다. 이번 변경은 v0.4 난이도·성장·사운드를 변경하지 않는다.

## 결과와 집계 기준

결과 화면은 전투 플레이 시간, 영웅/레벨, 몬스터 처치 수와 처치율, 놓친 수와 비율, 전체 등장 수, 보스 수와 골드를 보여준다. 플레이 시간은 시뮬레이션 전투 시간이며 일시정지/강화 선택 시간은 제외한다.

- 전체 등장: 실제 생성에 성공한 일반 적과 보스. 상한으로 거부된 생성은 제외한다.
- 처치: HP가0 이하가 되어 실제 처치 보상을 지급한 수. 반복 공격으로 중복 집계하지 않는다.
- 놓침(미처치): 전체 등장−처치. 화면 밖 이탈, 보스전 진입/상한으로 정리된 살아 있는 적, 종료 시 살아 있는 적을 포함한다.
- 놓친 비율: 미처치÷전체 등장×100. 등장0이면0%다. 결과 화면과 기록에 각 하위 원인도 표시하며, 정리된 적을 처치로 간주하지 않는다.
- 보존식: 전체 등장=처치+미처치, 미처치=이탈+전환/상한 정리+종료 시 생존. 보스 처치 수도 전체 처치에 포함되는 부분집합이다.

이번 종료 화면의 기록은 최근20회까지 기존 저장에 추가한다. 설정 또는 결과 화면의 ‘최근 원정 기록’에서 펼쳐 볼 수 있다. 자발적인 원정 종료도 ‘중도 종료’로 저장한다. 원정ID 중복 정산을 막고, 기록을 새 객체로 정규화하며 잘못된 기록/수치/비율은 검증한다. 저장을 다시 읽을 때 비율은 개수에서 다시 계산한다. 이전 저장에 없던 전투 집계를 소급 생성하지 않는다. 기존 골드/성장/기록/음량은 유지한다.

APK0.4.1/versionCode5, 패키지com.everpath.game와 기존 디버그 서명을 유지한다. 빌드 정보와 SHA는 artifacts/android/build-info.json 및 .apk.sha256을 기준으로 한다.

## 저장과 업데이트

현재는 앱 WebView의 localStorage에 저장한다. 일반 브라우저와 앱 저장은 별개다. 같은 패키지·서명·저장 origin을 유지하며 기존 앱 위에 업데이트하면 정상적으로 이어 쓸 수 있다. 앱 삭제/데이터 삭제는 보존 대상이 아니고 클라우드 동기화도 없다. localStorage는 OS의 공간 회수 등에서 영구 보존을 보장하지 않으며, 장기 저장 강화는 Capacitor Preferences로의 이전을 고려할 수 있다. 이번 변경에서 저장 백엔드를 변경하지는 않았다.

참고: [Capacitor 공식 저장 안내](https://capacitorjs.com/docs/guides/storage).
