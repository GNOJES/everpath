# 초반 전투와 중·최종 보스 비교 · v0.6.4

정상 체력, 시드 6개와 강화 선택 방식 3개를 조합해 캐릭터·영구 강화 단계마다 18회씩 전투 로직을 실행했습니다. 입력은 적과 장판을 피해 움직이는 규칙을 사용했습니다. 각 항목은 v0.6.3 → v0.6.4입니다.

| 캐릭터 | 첫 처치 중앙값(초) | 첫 강화 중앙값(초) | 1분 처치 중앙값 |
|---|---:|---:|---:|
| 전사 | 9.8 → 2.3 | 22.7 → 14.6 | 61 → 62.5 |
| 궁수 | 1.8 → 1.7 | 9.9 → 10.1 | 83 → 83.5 |
| 마법사 | 2 → 1.9 | 9.5 → 9.4 | 79 → 83.5 |

| 영구 강화 | 쌍둥이 전사 | 쌍둥이 궁수 | 쌍둥이 마법사 | 모르바 전사 | 모르바 궁수 | 모르바 마법사 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 3 → 8 | 18 → 15 | 3 → 6 | 0 → 0 | 0 → 0 | 0 → 0 |
| 5 | 7 → 13 | 18 → 18 | 11 → 14 | 0 → 0 | 0 → 0 | 0 → 0 |
| 10 | 17 → 17 | 18 → 18 | 18 → 18 | 0 → 0 | 0 → 0 | 0 → 1 |
| 15 | 18 → 18 | 18 → 18 | 18 → 18 | 12 → 7 | 3 → 7 | 3 → 11 |
| 20 | 18 → 18 | 18 → 18 | 18 → 18 | 18 → 18 | 12 → 13 | 16 → 18 |

6분은 그롬 두 마리 모두 처치한 횟수입니다. 도달하지 못한 원정도 분모에 포함됩니다. 무강화 v0.6.4에서 6분 보스전 도달은 전사 16회, 궁수 17회, 마법사 6회였습니다. 10분은 모르바 처치 횟수입니다. 원정에서 번 골드만 투자한 별도 48경로의 첫 클리어 중앙값은 전사 8회·궁수 9회·마법사 7회였습니다.

전사는 검격 각도를 유지한 상태에서 초반 사거리와 공격 주기, 이동 속도를 조정했습니다. 마법사는 기본 체력을 올렸습니다. 쌍둥이 그롬 개별 체력과 최종 보스의 체력·원거리 저항을 함께 조정했습니다.

재현 명령은 `npm run test:campaign`입니다.
