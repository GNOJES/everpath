# 무강화 6분전 비교 · v0.6.5

영구 강화 0, 정상 체력, 반응형 이동과 원정 중 강화 선택 방식 3종을 적용했습니다. 이전 검증 시드 6개와 별도 시드 6개를 두 버전에 동일하게 실행했습니다. 각 항목은 36회 원정 중 해당 조건을 달성한 횟수입니다.

| 캐릭터 | 6분 도달 | 그롬 두 마리 모두 처치 |
|---|---:|---:|
| 전사 | 34 → 36 | 11 → 28 |
| 궁수 | 34 → 34 | 32 → 33 |
| 마법사 | 11 → 33 | 11 → 23 |

궁수는 긴 사거리와 이동 속도, 관통 화살로 거리를 유지하면서 공격할 수 있습니다. 기존 시드 18회에서 마법사의 4~6분 사망 12건 중 11건은 적 투사체에 맞은 결과였습니다. 전사는 주로 6분 이후 적과의 충돌로 쓰러졌습니다.

- 전사는 모르바 이외 적과의 충돌 피해를 50% 덜 받습니다.
- 마법사는 해골 궁수의 화살 피해를 75% 덜 받습니다. 단일 대상 주문을 사용합니다.
- 6분 그롬의 개별 체력을 낮추고 돌진 뒤 회복 시간을 1.6초에서 2.35초로 늘렸습니다. 장판 반경은 75에서 60으로 줄였습니다. 궁수의 대미지는 이 두 그롬에게만 70%가 적용되어 체력 감소에 따른 이점을 상쇄합니다.

중반 생존이 좋아진 마법사는 원정 한 번에 더 많은 골드를 얻습니다. 모르바에게 들어가는 마법사 피해 배율을 84%에서 62%로 낮춰 반복 성장에 맞췄습니다. 캠페인 시뮬레이션에서 모르바는 무강화 54회 모두 클리어하지 못했고, 영구 강화 15단계에서 세 직업 모두 18회 중 6회 클리어했습니다.

기존 시드 `42, 271, 2026, 91, 777, 4096`은 `npm run test:campaign`으로 재실행할 수 있습니다. 별도 비교에는 `17, 123, 515, 1337, 5331, 65537`을 사용했습니다. 전투 로직 시뮬레이션 수치입니다.
