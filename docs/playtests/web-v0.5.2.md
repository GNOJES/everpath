# 웹 밸런스 검증 · v0.5.2

v0.5.1 운영 웹에서 모바일 Chrome의 터치 입력과 가속 시계를 사용해 영구 강화 0단계로 캐릭터당 한 번씩 플레이했습니다. 같은 시드와 이동 경로에서 전사·궁수·마법사의 첫 강화는 각각 19초·11초·20초였고, 30초 처치는 20·19·16마리였습니다.

아래 표는 영구 강화 4종을 같은 단계로 맞췄을 때의 10분 보스 **도달 / 클리어** 횟수입니다. 각 칸은 버전마다 18회입니다. 같은 시드 6개와 강화 선택 방식 3개를 사용해 기본 도전에서 실제 전투 로직을 버전마다 270회 실행했습니다.

| 영구 강화 단계 | 전사 v0.5.1 → v0.5.2 | 궁수 v0.5.1 → v0.5.2 | 마법사 v0.5.1 → v0.5.2 |
|---:|---:|---:|---:|
| 0 | 0 / 0 → 0 / 0 | 0 / 0 → 0 / 0 | 2 / 0 → 2 / 0 |
| 5 | 1 / 0 → 0 / 0 | 0 / 0 → 0 / 0 | 5 / 0 → 5 / 0 |
| 10 | 4 / 1 → 1 / 0 | 0 / 0 → 0 / 0 | 10 / 1 → 10 / 1 |
| 15 | 13 / 13 → 13 / 9 | 7 / 2 → 10 / 5 | 10 / 3 → 11 / 4 |
| 20 | 15 / 15 → 16 / 15 | 16 / 9 → 16 / 11 | 13 / 6 → 13 / 8 |

전사는 첫 검격 피해를 높여 초반 슬라임을 한 번에 처치할 수 있게 했습니다. 무기 5레벨의 진화 전 피해 배율은 유지하고, 진화 피해 보너스는 +65%에서 +38%로 줄였습니다. 궁수 기본 체력은 105에서 114, 마법사는 85에서 95로 늘렸습니다. 모르바의 장판 피해를 낮추고, 보스전 진입 시 영구 체력 강화 단계에 비례해 체력을 최대 20% 회복합니다.

원정 보상만 투자한 48개 연속 재도전 경로에서 첫 클리어까지 중앙값은 전사 10회, 궁수 13회, 마법사 13.5회에서 각각 10회, 9회, 11회로 바뀌었습니다. 모든 경로의 가장 이른 클리어는 4회차였습니다. 모의 조작과 강화 선택 규칙에 따른 값입니다.

재현 명령은 `npm run test:campaign`입니다. 시드와 이동·강화 선택 방식은 `tests/helpers/playtest.ts`와 관련 시뮬레이션 테스트에서 확인할 수 있습니다.
