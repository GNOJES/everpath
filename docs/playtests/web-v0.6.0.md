# 전장과 전투 개편 · v0.6.0

밝은 민트색 잔디와 모래길, 명암 대비가 큰 캐릭터 색, 청색 HUD를 적용했습니다. 영웅은 검격, 직선 관통 화살, 단일 유도탄과 주문으로 구분됩니다. 적이 네 방향에서 들어오며 20초 이후 두 방향에서 동시에 들어오는 무리가 추가됩니다. 적 장판은 경계를 좁히고 예고 시간을 늘렸으며, 진행 링으로 발동 시점을 표시합니다. 판정은 화면에 표시한 원 안의 플레이어 중심을 기준으로 합니다.

## 초반 1분

같은 시드 6개와 강화 선택 방식 3개로 캐릭터당 18회씩 검증했습니다. 영구 강화 0단계에서 1분 평균 처치는 전사 39 → 67마리, 궁수 49 → 83마리, 마법사 38 → 85마리였습니다.

## 10분 보스

영구 강화 4종을 같은 단계로 맞춘 기본 도전에서 각 칸은 모의 플레이 18회 중의 클리어 횟수입니다.

| 강화 단계 | 전사 | 궁수 | 마법사 |
|---:|---:|---:|---:|
| 0 | 0 | 0 | 0 |
| 5 | 0 | 0 | 0 |
| 10 | 0 | 2 | 0 |
| 15 | 9 | 8 | 4 |
| 20 | 17 | 14 | 14 |

모르바는 원거리 공격에 피해 저항이 있습니다. 활의 연속 관통과 마법사의 단일 집중 피해가 근접 검격과 비슷한 시간대에 첫 클리어에 도달하도록 조정했습니다. 원정에서 번 골드만 투자한 48개 경로에서 첫 클리어 중앙값은 전사 8회, 궁수 8.5회, 마법사 8.5회였습니다.

재현 명령은 `npm run test:campaign`입니다. 브라우저 회귀 테스트는 터치, 결과 화면, 저장 백업과 복원을 포함합니다.
